# Ussama Aamir — Cinematic Portfolio

A responsive multi-page static portfolio built for GitHub Pages.

## Pages
- Home, About, Showreel, Portfolio, Photography, Contact
- Separate category pages for narratives, corporate films, development/impact, commercials, interviews, travel, and shows.

## Publish
Upload the contents of this folder to the root of `u55ama/u55ama.github.io`, replacing the current `index.html` only when you're ready. GitHub Pages publishes from the repository branch configured in Settings → Pages. See GitHub's [Pages quickstart](https://docs.github.com/en/pages/quickstart).

## Notes
- `projects.json` contains editable project metadata and YouTube video IDs.
- Project cards use YouTube thumbnails; the amber cloud hero is in `assets/amber-clouds.jpg`.
- Photography cards are intentionally placeholders until you provide photographs.
- Contact email works via `mailto:`. The form requires your own Formspree form ID before it can submit.
- No year or role/credits fields are used.
- Test by opening `index.html` in a local static server before publishing. Fetching `projects.json` may not work from a `file://` URL; GitHub Pages serves it correctly.
